Password

At least 12 characters, with three of: lowercase, uppercase, digits, symbols. Changing it signs out your other sessions.

Two-factor authentication

Scan the code with your authenticator app, or type the key in, then enter the 6-digit code it shows.

Your administrator requires two-factor authentication for this account, so it cannot be turned off.

API tokens

A token lets a script use ARES Terminal Console as you, through /api/v1/ (see /api/v1/openapi.json). It never has more rights than your account, and it stops working when you revoke it, when it expires, or when your account is disabled.

Scopes

Keep the token in a secret manager. Never put it in a URL, a committed script or a log.
